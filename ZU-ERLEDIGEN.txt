 1) BESTELL-FORMULAR FREISCHALTEN  (wichtigster Punkt — dauert 2 Minuten)
------------------------------------------------------------------------
Datei: js/bestellung.js

Die Bestellung wird per Gratis-Dienst "FormSubmit" an dich gemailt.
Du brauchst dort KEIN Konto.

  [ ] Website öffnen, ein Produkt in den Warenkorb legen und eine
      TEST-Bestellung abschicken.
      ACHTUNG: Per Doppelklick auf index.html geht das NICHT — FormSubmit
      lehnt Seiten ab, die als Datei geöffnet wurden ("Make sure you open
      this page through a web server"). Stattdessen im Projektordner eine
      Eingabeaufforderung öffnen (im Explorer "cmd" in die Adressleiste
      tippen), dort eingeben:

            python -m http.server 8765

      und dann im Browser http://localhost:8765/index.html aufrufen.
      (Genauer beschrieben in README.md, Abschnitt 1.)
      Alternativ: erst Punkt 3 "Live-Gang" machen und gleich online testen.
  [ ] In deinem Postfach imkerei@noah.co.at kommt eine Mail von FormSubmit
      mit dem Betreff "Confirm your email".
      -> Darin auf "Activate Form" klicken. Ab jetzt läuft es.
  [ ] FormSubmit zeigt dir danach einen zufälligen Code an
      (z. B. "a1b2c3d4e5f6..."). Diesen Code in js/bestellung.js ganz oben
      bei BESTELL_ZIEL anstelle der E-Mail-Adresse eintragen.
      Grund: Dann steht deine echte Adresse nicht im Quelltext und kann
      nicht von Spam-Robotern abgegriffen werden.
  [ ] Noch eine Test-Bestellung machen und prüfen, ob die Mail ankommt.

  [ ] Danach in js/bestellung.js prüfen, ob die Zeiten passen:
        ABHOL_ZEITFENSTER  = die auswählbaren Zeitfenster
        VORLAUF_TAGE       = wie viele Tage Vorlauf du brauchst (jetzt: 1)

  NORMAL BEIM TESTEN, KEIN FEHLER:
  Solange die Website noch nicht online ist, landest du nach dem Absenden
  auf der "Danke"-Seite von FormSubmit statt auf unserer eigenen. Grund:
  FormSubmit kann nur auf eine echte Internet-Adresse zurückleiten, nicht
  auf eine Datei am eigenen Rechner. Nach dem Live-Gang (Punkt 3) stimmt
  das automatisch — die Adresse steht in js/bestellung.js bei DANKE_SEITE.
  Aus demselben Grund bleibt der Warenkorb beim lokalen Testen gefüllt.
